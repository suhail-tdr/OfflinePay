# Security & Privacy Policy – OfflinePay

- **No UPI PIN Storage:** OfflinePay explicitly guarantees that the user's UPI PIN is **never** requested, collected, stored, or transmitted.
- **Authorized Banking Channels:** All actual financial transactions are executed exclusively through authorized telecom USSD channels (`*99#`) or banking apps.
- **Local Encryption / Storage:** Local transaction records are stored securely on-device using Room Database.
